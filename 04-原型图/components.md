# 组件规范 · NEW-056

所有尺寸与颜色来自 `design-system.md`，实现时直接使用 `assets/mock.css` 的类名与变量。

## 按钮 `.btn`

| 类型 | 类名 | 高度 | 场景 |
|---|---|---|---|
| 主按钮 | `.btn.pri` | 32px | 每页唯一主操作（提交立项、发布公示） |
| 次级 | `.btn` | 32px | 查询、重置、导出、返回 |
| 强调 | `.btn.acc` | 32px | 确认冲正、重新公示等需注意的操作 |
| 危险 | `.btn.dgr` | 32px | 驳回、注销、删除，红色描边，二次确认 |
| 小号 | `.btn.sm` | 26px | 表格行内、卡片头部 |
| 文字按钮 | `.btn.gh` | — | 卡片头「更多」 |

内边距 0 14px，圆角 6px，图标 12–13px 置于文字左侧，间距 6px。
表单底部按钮右对齐，主按钮在最右。危险操作必须二次确认弹窗。

## 输入与筛选

- 输入框 `.inp`：高 32px，圆角 6px，描边 `--line`，聚焦描边 `--primary` + 3px 主色微光。
- 下拉 `.sel`：宽 180px（搜索下拉 180–240px），右侧 10px 处箭头图标。
- 筛选区 `.filter`：白底卡片，条目 `.fi-item`（label 12px + 控件），右侧「查询 / 重置」，条件超过 6 个换行。
- 表单 `.form-grid`：两列，列距 20px、行距 14px；标签在控件上方，必填项红星 `<em>*</em>`，提示文字 11px `--text-3`。
- 金额输入右侧带单位「元」`.with-u`；文本域 `.ctl.ta` 高 76px，行高 1.7。
- 校验失败：控件描边 `--danger` + `#FFF9F9` 底色，下方红色 11.5px 提示。

## 表格 `.tbl`

- 表头：`#FAFAFB` 背景，11.5px/600，`--text-2`，下边框 1px。
- 行：12.5px，内边距 9px 12px，行分隔线 `#F0F2F3`，hover `#FCFBFB`。
- 金额/数量列：右对齐 + 加粗 + `tabular-nums`（`.num`）。
- 首列常为「缩略图 + 名称 + 编号」`.rowimg`：40×30 圆角 4px 缩略图 + 名称 12.5px/600 + 编号 10.5px `--text-3`。
- 操作列右对齐，最多「查看 + 2 个高频操作」，其余进「更多」菜单。
- 空状态：`.empty` 居中，说明原因 + 下一步操作按钮。

## 分页 `.pager`

卡片底部，上边框 1px。左「共 N 条」，右「每页条数下拉（88px）+ 页码 + 下一页」。
页码 28×28，圆角 5px，当前页酒红底白字。

## 标签 `.tag`

高 21px，圆角 11px，11px 字，前置 5px 圆点（`.plain` 去掉圆点）。
语义：`.s` 成功绿 / `.w` 警示金 / `.d` 危险红 / `.n` 进行中蓝 / `.m` 主色（已立项）/ `.g` 中性灰（已注销、已归档）。

## KPI `.kpi`

卡片内 36px 图标块（浅主色/浅金/浅绿/浅蓝四种）+ 标签 11.5px + 数值 21px/700 + 增减说明 11px。
一行 4 个，间距 12px，卡片高约 74px。

## 图表 `.chart`

卡片高 200px（紧凑 172px），头部「标题 12.5px/600 + 口径说明 10.5px」，右侧图例可换行。
可用图形与约束：
- 环形图：132×132，中心 26px 白孔，中心显示合计与口径；图例右侧 4 行，值右对齐（金额带 ¥ 与千分位）。
- 横向条形：名称列 74px，轨道 9px 高圆角，填充需 `display:block` 才生效。
- 柱状：`.bars` 高 126px，柱顶显示数值，`column-reverse` 保证堆叠顺序。
- 漏斗：4 级，宽度按首级等比，左侧名称列 64px，右侧转化率。
- 折线：SVG 126px 高，`vector-effect:non-scaling-stroke` 防拉伸，网格线 `#EDEFF0`。

## 评分面板

- `.score-hero`：渐变浅底（`#FBF4F4 → #F8F1E8`），大号分数 40px/700 主色，右侧等级标签 + 规则版本 + 计算时间。
- `.score-bar`：因子名 118px，轨道 8px，填充 `.fill`（span 必须 `display:block`），右侧分值 52px 右对齐。
- 等级标签 `.grade`：A 绿 / B 蓝 / C 金 / D 红，26px 高，圆角 6px。
- 必须同时给出「因子明细表 + 改进建议 + 计算留痕入口」，不允许只显示分数。

## 抽屉与弹窗

- 右侧抽屉 `.drawer` 宽 520px，头 52px（标题 + 关闭），体可滚动，底 56px 右对齐按钮。
- 弹窗 `.modal` 宽 520px，圆角 10px，用于二次确认与简短表单。
- 审批、流转、登记支付统一用抽屉，抽屉内先展示单据摘要再放表单。

## 状态机步骤条 `.steps`

横向 5–6 段：已完成节点实心主色 + 白字序号，未完成灰描边，连接线 1px `--line`。
用于活动详情（待审批 → 已立项 → 进行中 → 已结束 → 已结项）。

## 时间线 `.timeline`

左侧竖线 + 8px 圆点，事件标题 12px/600 + 时间 10.5px `--text-3` + 说明 11.5px `--text-2`。
用于状态流水、审批留痕、冲正记录、公示版本。

## 提示条 `.alert`

| 类 | 底色 | 用途 |
|---|---|---|
| `.alert.i` | 浅蓝 | 规则说明、口径提示 |
| `.alert.w` | 浅金 | 待整改、额度预警、校验提醒 |
| `.alert.d` | 浅红 | 阻断项、校验失败 |
| `.alert.s` | 浅绿 | 校验通过 |

高约 36–60px，圆角 6px，左侧 14px 图标，正文 12px，行高 1.8。

## 门户卡片 `.acard`

封面 112px（真实活动图片，1:1 使用种子图），内容区 11px 13px：标题 13.5px/600 两行截断、元信息行（社团/时间/地点 11.5px）、底部「状态标签 + 报名按钮」。
三列栅格，间距 12px。

## 登录页

`grid 1.05fr / 0.95fr`：左侧酒红渐变品牌区（同心圆装饰 + 主标语 + 3 条卖点 + 落款），右侧表单区（品牌、欢迎语、账号、密码、记住账号、登录按钮、演示账号提示）。
输入框高 42px，登录按钮高 42px 圆角 7px；实现阶段左侧或整体背景替换为真实校园社团实景图（本地 `src/assets/login-bg.jpg`）。
